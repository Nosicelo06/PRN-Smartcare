PRN SmartCare

Academic Project | Status: In Development

Project Overview

PRN SmartCare is a university academic project focused on developing a digital clinic management system for public clinics.

The purpose of the system is to help public clinics create, store, and retrieve patient files digitally. The project aims to improve the management and accessibility of patient information while reducing reliance on paper-based patient files.

Purpose

The system is designed to:

* Allow public clinics to create and store patient files digitally.
* Allow authorized clinic staff to retrieve patient information when needed.
* Help clinics manage patient records more efficiently.
* Support better continuity of care when patients use different public clinics.

Planned Notification Features

A future improvement is to add a notification system that can:

* Notify patients when they are overdue to collect their medication.
* Notify patients when they have only a few days remaining before they need to collect their medication.
* Notify patients when they are due for a follow-up or need to see a doctor.

Cross-Clinic Patient Records

A future goal of PRN SmartCare is to allow public clinics to securely share relevant patient records through a connected database.

This would allow a patient's authorized medical record to be accessed by another participating public clinic if the patient moves to another area and continues receiving healthcare through the public clinic system.

The goal is to improve continuity of care and reduce the difficulty of accessing patient information when patients change clinics.

Current Features

The project is currently in the **development stage**.

At this stage, I have developed an initial **account prototype** as part of building the system.

More features will be added as development continues.
